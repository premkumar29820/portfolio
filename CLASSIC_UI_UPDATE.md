# Classic UI Update

- Redesigned the Home page with a classic editorial layout.
- Changed the visual theme to ivory, deep green, charcoal, and restrained gold accents.
- Added a dedicated phone icon and phone contact treatment on the Home and Contact pages.
- Added a three-column home facts strip for location, specialization, and direct contact.

- Kept the existing React routes, API usage, social links, projects, and form behavior intact.

Run inside `frontend`:
